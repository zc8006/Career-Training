# PEGACPSA25V1 学习与认证训练规则

[[../PEGA_MOC|← PEGA Knowledge Map]]

## 目标

目标认证：**Certified Pega System Architect '25**  
考试代码：**PEGACPSA25V1**

学习目标不是单纯刷题或背答案，而是做到：

1. 真正理解 Pega 的核心概念和业务场景。
2. 能看懂 PEGACPSA25V1 英文考试题干。
3. 能根据场景判断正确的 Pega 配置或最佳实践。
4. 通过持续练习建立自己的错题库、英文词库和考试知识体系。

官方主教材：Pega Academy — System Architect Mission v8。

## 总体学习原则

### 理解优先，不死记答案

每个知识点先回答：这个功能解决什么问题、什么时候使用、Pega 为什么这样设计。理解以后再进入考试题。

### 官方内容要“整页学习”，不能只看正文

后续不再把正文当成唯一考试范围。一个 Topic 的完整学习来源包括：

1. **正文说明**：定义、规则、限制。
2. **页面图示 / UI 截图**：结构、位置关系、配置方式。
3. **交互练习**：正文未展开但官方希望掌握的概念。
4. **Module Quiz / Knowledge Check**：真实暴露考试式场景和术语。
5. **官方反馈**：用于修正理解，而不是只记答案。

如果练习题出现正文未充分展开的新概念，应回到知识体系中补齐，而不是因为“正文没写”就排除。

### 深层理解六层法

每个知识点至少从六层理解：

1. **Definition**：官方定义是什么。
2. **Relationship**：它和 Case / Stage / Process / Step / Assignment / View 等概念怎么连接。
3. **Design intent**：Pega 为什么提供这个功能，解决什么问题。
4. **Scenario**：现实业务什么时候使用。
5. **Confusion / trap**：它最容易和什么概念混淆，错误选项为什么错。
6. **Exam English**：题目换一种说法时，要靠哪些英文关键词识别。

目标不是记住页面，而是做到：

> **题目换场景、换表达、换选项顺序，仍然能根据设计逻辑判断。**

### 官方教程是知识来源，考试题是检验和补全手段

固定顺序升级为：

**官方正文 + 图示 → 中文深层理解 → 业务例子 → 交互题补全知识 → 英文关键词 → 考试场景题 → 错题复盘 → 回写知识库**

不要求一次性把整个 Mission 看完再刷题。每学一个小知识点就立即做对应题验证。

### 一次只学习一个小主题

基础概念未掌握前不随意扩展复杂内容。例如 Case Lifecycle 按 Case → Stage → Process → Step → Case Lifecycle 逐层学习。

## 固定学习流程

### Step 1：看完整官方 Topic

不只读文字。正文、图片、图中标签、Note、交互练习、页面底部 Knowledge Check 都属于学习内容。

### Step 2：中文深层理解

先用中文讲清楚：

- 是什么
- 为什么存在
- 和上下游概念是什么关系
- 什么时候使用
- 不应该什么时候使用
- 与相似功能有什么区别

### Step 3：结合真实业务场景

尽量用简单业务流程理解 Pega，而不是单纯背定义。

```text
Case
 └─ Stage
     └─ Process
         └─ Step
```

### Step 4：从官方练习补知识

官方交互题和 Module Quiz 不是“学完后的附加题”，而是教材的一部分。

遇到新术语时：

1. 判断是不是当前模块真正要求掌握的概念。
2. 把它补到现有知识结构中。
3. 找出它和已学概念的关系。
4. 后续重新出变体题验证，而不是只记官方答案。

### Step 5：学习考试必备英文关键词

不做泛英语学习，只积累 PEGACPSA25V1 高频词。做题过程中遇到新的高频词持续追加。

### Step 6：训练英文题干拆解

固定方法：

**英文题干 → 找关键词 → 还原业务需求 → 定位 Pega 知识点 → 选择答案**

重点不是逐词翻译，而是读懂“谁、要做什么、有什么条件”。

如果题干没看懂：

1. 暂停答题。
2. 按短语拆开。
3. 标记真正影响答案的词。
4. 用压缩中文还原场景。
5. 再让用户作答。

### Step 7：考试题训练

默认一次一道题，每个小 Topic 通常先做 **5 道**验证掌握程度：

1. 只显示英文原题和选项。
2. 先独立作答。
3. 回答前不提示答案。
4. 回答后公布答案并用中文解释。
5. 提取关键英文词。
6. 对应到官方 Pega 知识点。
7. 必要时解释错误选项。
8. 错题加入后续随机复习。

### Step 8：固定收口标准，禁止无限刷题

每个小 Topic / Module 的复习使用固定闭环：

```text
知识点复习
→ 5 道基础 / 场景题
→ 错题复盘
→ 5 道定向验证题
→ 达标后停止当前单元连续刷题
→ 进入下一 Topic / Module
```

过关标准：

- 定向验证 **4/5 或 5/5**：本轮通过。
- **3/5 或以下**：暂停推进，重新讲清错点后再验证。
- 同一知识点连续错 **2 次**：立即停止继续出新题，先做概念澄清。
- 已通过的单元不再连续刷基础题，只在后续学习中随机混入旧错点。
- 用户没有主动打断时，助手也必须自动按此标准收口，不能无限连续出题。

通过不等于永久掌握。高频易错点继续按照第 2 天、第 4～7 天和后续随机复习规则出现。

## 题目难度

- **Level 1 基础概念题**：Case、Stage、Process、Step、Assignment、Data Object、View 等。
- **Level 2 简单场景题**：根据实际需求判断功能。
- **Level 3 考试风格场景题**：most appropriate、best practice、which configuration 等。
- **Level 4 综合题**：多个知识点混合。

基础正确率稳定后再升难度。

## 错题规则

每道错题至少记录：

```text
Topic:
Question:
My Answer:
Correct Answer:
Why I was wrong:
Correct concept:
English keywords:
Review date:
```

错误类型：知识点不会、概念混淆、英文题干没看懂、关键词漏看、多选少选/多选、Best Practice 判断错误。

对错题不能只写“正确答案是 X”，必须还原：

> **为什么这个场景属于这个概念，为什么其他选项不符合设计意图。**

## 英文专项规则

英语跟着 Pega 题目学，不单独学泛英语。

重点识别：

- 动作：configure / route / assign / validate / create / update / resolve / advance
- 条件：when / if / based on / depending on / even if / as long as
- 对象：case / assignment / data / view / process / stage
- 题目要求：best / most appropriate / should / ensure / two actions
- 路径关系：primary path / deviation / next stage / specific stage / previous step

每道题提取：关键词、固定搭配、真正影响答案的句子、可忽略背景信息。

## 复习规则

- 当天：新知识 + 立即练习
- 第 2 天：快速复习前一天错题
- 第 4～7 天：再次抽查
- 后续：随机混入旧题

复习不能只重复原题，要优先出：

- 相同知识点的换皮场景题
- 易混概念对比题
- 英文换表达题
- Choose Two / best / most appropriate 等考试式题型

掌握标准：**在没有提示的情况下可以独立判断，并能说出为什么。**

## 官方教程学习原则

每个 Module 都按：

```text
看完整官方内容
→ 讲清结构与设计逻辑
→ 做交互题 / 官方题
→ 发现正文外考点
→ 补全知识体系
→ 做 5 道变体题
→ 记录错题与英文词
→ 更新知识库
```

连续出错就暂停推进新内容。

## 助手训练规则

1. 一次默认只出一道题。
2. 一个小 Topic 默认先做 5 道题，不无休止刷题。
3. 用户回答前不泄露答案。
4. 先保证基础理解，再扩展难题。
5. 不加入超出 CPSA 范围的源码级内容。
6. 解释优先使用中文，保留关键 Pega 英文术语。
7. 英文没看懂时先拆题，而不是只给整句翻译。
8. 错题必须解释为什么错。
9. 高频错误自动进入后续复习。
10. 官方交互题 / Quiz 出现正文未讲透的知识时，要主动补全。
11. 不能只停留在表面定义，要说明结构关系、设计意图和适用边界。
12. 训练目标是考试能力 + 实际理解，不是背题库。
13. 5 题阶段结束后必须进行阶段判断，不因用户未打断而继续无限出题。
14. 定向验证达到 4/5 后，结束该 Topic / Module 的连续基础训练并推进下一内容。

## 阶段目标

1. 建立基础概念。
2. 按模块学习并练习。
3. 混合场景题。
4. Mock Exam：检查正确率、英文阅读速度、场景判断速度、易混点和多选题稳定性。

## 核心原则

> **理解 Pega 设计逻辑 → 看懂英文需求 → 判断正确配置 → 用官方题补全知识 → 用变体题验证真正掌握。**
