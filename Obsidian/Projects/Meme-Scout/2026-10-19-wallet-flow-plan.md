## 新假设 H3

GMGN 标记钱包出现持续、分散的实际净买入时，选出的币在24h扣费收益上优于同类普通候选。该假设独立编号 wallet-flow-study-v1；V7.5 与 signal-audit-v1 沿用原参数和各自样本。

“聪明钱包数增长”不能替代实际买卖记录；多个地址也可能属于同一人。此实验只描述已观察到的标记钱包流量，不代表全链净资金流入。

## 采集与覆盖

- BSC 先试点，默认每60秒请求官方 GET /v1/user/smartmoney，limit=200，API key只读认证；不使用需要钱包私钥的跟单接口。
- 保存交易hash、maker、链、合约、买卖方向、美元金额、成交价与时间；标识包含链/hash/maker/合约/方向。相同标识不同金额、价格或时间视为冲突。
- 检查相邻返回页是否有重叠、采样间隔是否超过150秒，以及字段无效、空列表和缓冲溢出。接口无已确认的翻页游标，重叠检查只是缺口诊断，不能证明穷尽所有链上成交。
- 本地保留30分钟、每链最多6000笔；上传最近30笔与最强4个单币完整窗口。单币超过200笔证据时不截取造信号，只观察。
- 网站独立重算指标、验证字段与交易一致性，并检查服务器接收间隔。只有紧凑轮询元数据保存72小时，最新窗口替换保存；入组样本冻结完整证据。
- 429进入全局GMGN冷却；401/403仅暂停钱包接口6小时，主采集继续。原有排名、持仓按合约报价和模拟任务保留。

## 冻结的准入规则

| 项目 | wallet-flow-study-v1 |
|---|---|
| 观察期 | 收到真实有效记录后至少48小时 |
| 24h质量 | 至少600轮；完整轮询率≥95%，时间覆盖≥95% |
| 时间覆盖 | 仅累计相邻两轮均完整、间隔≤150秒的区间；停机不填充 |
| 当前窗口 | 最近30m至少12轮且全部完整；最新采样≤150秒 |
| 钱包分散度 | 30m至少3个净买入地址，逐地址扣除卖出 |
| 持续性 | 前、后两个15m已观察净买入均为正 |
| 集中度 | 最大买方占总买入美元金额≤60% |
| 价格距离 | 当期GMGN现价相对窗口最早买价在−10%～+20% |
| 公共检查 | 现有GMGN报价、风险、连续快照、最低流动性、费用均通过 |
| 交易范围 | 先限已有完整GMGN历史快照的BSC币；榜外缺风控/历史时不模拟入场 |
| 对照 | 同采集周期、同链同币龄档，流动性0.5～2倍，报价差≤2分钟 |
| 配对算法 | 流动性最近的3个普通候选中固定种子选择，保存当时名单 |
| 容量 | 每日最多1对、间隔至少24h、同时最多8对，旧实验先用共享报价预算 |
| 金额与费用 | 每边虚拟$10；沿用现有Gas、1%平台费和池深滑点模型；BSC每次Gas仍为固定$0.05估计 |
| 退出观察 | 独立估算15m/1h/6h/24h/7d整仓退出，时点之间不重复扣多次退出费 |
| 缺失 | 到期后10分钟内首个合格报价；没有则未知，不填零收益 |

对照选择不参考其钱包信号；对照可能也符合钱包信号，这会稀释组间差异。未在完整短名单内的钱包证据记录为未知，不能称为“没有聪明钱”。本实验检验有钱包筛选的候选相对于普通同类候选，不能解释成钱包阳性与钱包阴性的因果试验。

首日优先跟价；之后低频保留至第7天，临近到期恢复优先级。共享容量不足时两边一起推迟，不建立半对照。钱包采集失效只阻止新入组，已入组两边仍记录到期结果。

## 阶段复核与自我成长

先查48h的覆盖是否可用；再看入组数量、不能入组的原因和24h完整配对差。第7天是初筛时间，不要求一周内得出盈利结论。按每天最多1对，30对至少需约一个月入组。

最低人工复核起点：30个完整24h配对、5个不同日期、距首组至少7天、到期配对完整率≥80%。同时检查绝对扣费收益、相对对照均值/中位数、剔除最大赢家后结果、额外成本压力和币龄分层。未达标就延长或先修数据；达到也只提出下一批独立复验，不自动改主策略。

下一步只推进这一条新信号线。新币迁移后的买盘另留后续假设，避免同时试多个方向再挑最好看的结果。

## VPS 启动与验收

网站「模拟账户 → 钱包行为有没有选币优势」提供升级步骤：[升级说明](https://meme-scout.zc8006.chatgpt.site/wallet-update-guide.txt)。

在当前Oracle采集器VPS，ubuntu用户直接执行下面整段，sudo负责使用root；令牌只从现有服务器文件经curl标准输入传递：

```bash
sudo bash <<'SH'
set -euo pipefail
task_update=$(mktemp)
trap 'rm -f "$task_update"' EXIT
task_token=$(cat /etc/meme-scout/sites-bypass.token)
printf 'header = "OAI-Sites-Authorization: Bearer %s"\n' "$task_token" |
  curl --fail --silent --show-error --config - https://meme-scout.zc8006.chatgpt.site/update-collector.sh --output "$task_update"
unset task_token
bash "$task_update"
SH
```

2026-10-19 12:32（北京时间）第44版修复sudo找不到Node的问题：优先从运行中采集器的/proc/<MainPID>/exe取得Node绝对路径，再检查systemd的ExecStart及命令路径；Node检查均在停止服务前完成。不会另行安装Node或改变服务配置。

更新器校验固定SHA-256，备份采集器，保留配置和状态，停止服务后检查真实token/info与smartmoney只读权限，通过才安装；失败恢复原采集器。若无smartmoney读取权限，需要在GMGN检查现有key权限，不能凭本地模拟测试视为已开通。

验收日志：gmgn_wallet_check且records>0，随后gmgn_wallet_collected。网站必须出现真实首次采样时间与覆盖比例；48h、覆盖和风控全部达标后，后台自动按固定规则筛查。当前没有VPS终端连接，本次没有执行远端升级，也没有确认真实smartmoney权限。
