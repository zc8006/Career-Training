# Meme Scout：选币优势验证与改善方案

[[Projects/Meme Scout|← Meme Scout 项目]]

## 目标与判断

先验证当前技术信号是否比同类未入选币带来更好的扣费收益，再决定更换选币依据或修改买卖规则。当前评分主要衡量流动性、交易笔数、换手与买单占比，尚未验证为预测盈利的能力。提高分数门槛、延长确认或调整止损，都需要新样本证据。

继续使用 GMGN。模拟账户、入场研究和退出研究分别统计；不把信号达标率、事后最高价或历史其他版本的收益当作当前策略胜率。

## 第一阶段：本次实施

### 1. 冻结基准并建立前瞻同类对照

协议：`signal-audit-v1`；基准：`paper-v7.5-gmgn-contract-tracking` 的技术信号。

- 在主账户现金、冷却、持仓额度限制之前判断技术信号，实验独立运行。
- 从本次发布后的新观察入组，历史赢家不回填。
- 同一币在该版本只用一次，不能先做对照、以后又当信号重复计数。
- 人工指定观察币不进入本实验。
- 原 V7.5 模拟账户及既有 entry-study-v3、improvement-study-v4 的买卖参数继续保留。

对照配对条件：

| 条件 | 固定定义 |
|---|---|
| 链 | 相同 |
| 币龄 | 同档：0–6小时、6–24小时、1–7天、7–30天、超过30天 |
| 流动性 | 对照为信号币的0.5–2倍 |
| 报价时点 | 相差不超过2分钟 |
| 风险与执行 | 两边均满足共同合约风险、最低流动性、连续历史、报价与Gas时效、计划卖出次数成本预算校验 |
| 技术信号 | 信号组满足完整技术条件；对照不满足 |
| 选择方法 | 找流动性最近的3个合格对照，以固定哈希算法选1个；保存种子和当时完整候选名单 |
| 缺少匹配 | 保留首次小时筛查记录，等待，不强行配对 |

评分、涨幅、X资料、确认条件属于待检验的信号特征，不把它们全部匹配掉。该对照只代表当前GMGN采集覆盖内的同类币，不代表全市场随机样本。

### 2. 固定观察时点并计入成本

两边各独立预留10美元，包含买入Gas与手续费；滑点影响执行价及获得数量。观察15分钟、1小时、6小时、24小时、7天。

- 每个时点分别估算一次整仓退出，属于独立持有期比较，不是连续卖出5次。
- 采用到期后10分钟内首个、且在该窗口内完成估值的有效GMGN报价。
- 计入对应退出Gas、手续费与池子深度滑点；费用不在净收益上重复扣除。
- 无有效报价、Gas过期、流动性为零或无法核查成交时，保留为未知，不按零收益或币价归零计算。
- 各时点分别使用两边都有结果的完整配对，展示缺失与仍在观察的数量。
- 首日另记采样最高/最低扣费变现估算收益与最大报价间隔；缺口超过20分钟时，路径不足以精确归因。
- 采样极值不等于可以抓住的利润。

### 3. 配合现有采集能力

- 每个北京时间自然日最多2对，入组间隔至少6小时，同时最多16对。
- 两边一起进入原有GMGN合约队列，不依赖继续留在热榜。
- 首日优先采价，其后与其他后续观察轮转；7日到期前30分钟恢复优先级。
- 两边一起预留采样名额；名额不足时整个配对等待。
- 共享现有20合约/轮预算，并保留4个后续观察名额；持仓优先。
- 复用现有采集器接口，本次不需要重新安装VPS服务，不转移GMGN API Key。

### 4. 改善亏损归因

最近亏损复盘增加精确买入版本，以及相对最近24小时最早已保存合格小时观察的等待时间与价格变化。

该小时记录不保证是最初出现信号的时刻；资料不足时留空。等待较久且买价更高，只产生“入场延迟/追高”的待验证线索。持有期采样表现、退出延迟、费用和旧来源成交异常分别保留。报价不完整或成交证据存疑时，不强行给出价格路径原因。

## 第一周检查与后续升级

主指标固定为：24小时扣费配对净收益差。

第一周先检查：

1. 两边是否成功入组并持续获得报价。
2. 缺失是否集中于某链、某币龄或高风险币。
3. 固定持有期是否出现初步收益差。
4. 亏损更接近缺少后续上涨、等待后买高，还是已有上涨后退出不佳；这些是研究线索。

进入人工复核前，至少需要：距首组7天、30个24小时完整配对、覆盖5个北京时间日期、到期配对完整率80%。这些是人为初筛门槛，不是统计显著性证明。每日最多2对，30对至少需约两周入组；样本不足继续积累。

初步有希望还需要：信号组绝对净收益为正、平均及中位配对差为正、去掉最好一组仍有优势、额外成本压力后仍成立。随后必须在新时间段独立复验，再另立策略版本。

## 第二阶段：尚未接入

- GMGN聪明钱/KOL真实买卖记录：先核验当前API权限、字段、时间和采集覆盖，再研究多钱包持续净买入；钱包标签不是盈利保证。
- 新币创建、迁移完成后的持续买盘与流动性：与当前热榜来源分开建立前瞻实验。
- 已有回调与二次入场研究继续观察，避免把旧实验重新包装成新方向。
- 更高频持仓采样需先评估配额、带宽与执行延迟，不能直接认定更快就能盈利。
