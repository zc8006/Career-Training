# Day 2 动作与配音自然度实验

今天继续打磨第一集《旧版本》，暂不进入第二集。用户反馈“整体动作表情不自然”“配音也不太好”，并提出延长单个生成镜头以改善连贯性。当前工作是验证一个局部镜头，不能把已准备的方案记为改进成片。

## 当前基线与检查证据

- 基线：第一集v7，实测55.291667秒，720×1280，24fps。
- 已从成片抽查0～5秒、16.8～19秒、36～39.5秒的连续帧，查看了手机开场、认名反应和对白近景。
- 认名反应在成片中约2秒。连续帧可见眉眼与头部变化，但仅凭抽帧不能判断完整运动是否自然。
- 对白近景中嘴部变化较突出，头肩变化较少；这提示需要检查表演是否像人物在说话，而不只是嘴巴开合。这是视觉判断，不是口型同步验收。
- 未直接听辨配音。音色、情绪和台词自然度问题目前依据用户反馈；时长、静音和音量分析不能代替听辨。
- 已从原始认名视频首帧提取无字幕的参考图。未修改原v7，未提交任何付费生成。

## 实验顺序

1. 先做一个10秒、无对白的连续认名反应，单独看表演；保留原版作比较。
2. 使用同一份短文试听两个音色候选，先选音色，再调节停顿与情绪。
3. 两项分别通过后，合成一段约10～15秒的小样；实际长度依据采用动作和音频确定。
4. 检查改善是否来自清楚的动作与情绪，而不是单纯变长。采用多少秒以观感为准。
5. 形成方法后再处理门口对白、失声等其他镜头，不整片同时重做。

10秒是本次候选目标，不代表所有镜头都应该变成10秒。MiniMax官方API文档列出H3为4～15秒、H3 Max为5～15秒；用户海螺网页的模型、时长与会员权限以实际页面为准。不要把API价格当成网页积分报价。

## 认名镜头提示词

固定机位，单镜头连续表演，时长10秒。保持参考图中林默的面容、灰衬衫、左袖口咖啡渍、电脑位置、办公室布局和半写实3D动画风格一致。男子起初看着电脑，手指有少量自然的打字动作。读到某一行后，手指先停下，视线停在那一行，短暂停顿；随后眼睛沿着同一行重新确认，身体轻微靠近屏幕。确认名字后，眉毛轻轻抬起，头部稍微后撤，眼神由专注变成难以置信，最后仍在看屏幕。动作之间有自然的先后和缓冲，呼吸与偶尔眨眼保持克制；不要让眼睛、眉毛、头和肩在同一瞬间一起改变。情绪是疑惑和意外，还没有进入极度恐惧。嘴唇保持闭合，这是内心反应，不说话。不转头、不站起、不挥手，不做夸张瞪眼或连续重复点头。灯光全程稳定，画面不缩放、不推拉、不摇晃。不添加文字、字幕、其他人物、对白或音乐。

## 配音测试正文

日志的最后一条，写着我的名字。
我盯着那行字，又看了一遍。
没错，是我。

这份文本是实验改写，尚未替换Day01定稿。配音基调：自然的第一人称回忆，前句陈述事实，发现名字时略有迟疑，后句逐渐紧绷；不使用搞笑、播报或突然切换的大幅惊恐。

先用同文、同语速比较两个短候选。选定基础音色后，再调停顿与表演。两位外观相同的林默可以共享基础声线，通过说话态度区分角色，不强行改成完全不同的人声。

## 验收依据

| 项目 | 检查方式 |
| --- | --- |
| 阅读与认名 | 不听旁白，能看出他读到异常信息，停手并再次确认 |
| 动作顺序 | 视线、手、头和身体有合理先后，不像一组同步机械指令 |
| 表演幅度 | 疑惑逐渐变成难以置信，不从普通阅读直接跳成极度恐惧 |
| 连续性 | 脸、手、袖口、视线、电脑和灯光稳定，动作没有反复重置 |
| 配音 | 完整听三句，是否像人物在讲述，而非逐句念稿；由用户实际试听判定 |
| 合成 | 声音与认名动作相互支持，没有为了凑时长冻结画面 |
| 成本 | 记录模型、时长、积分、候选数和采用秒数，包含废片 |

每次先生成1个视频候选；下一次重试前记录“失败点→改动→验收条件”，沿用每个镜头最多3次付费尝试的上限。发现开头参考状态不对，应先修首帧，不能靠反复加长解决。

## Codex的分工

Codex适合在本地管理媒体、修改剪辑脚本、运行FFmpeg、生成对比片、检查时长和同步、记录版本；它需要实际可用的视频/TTS工具或API才能提交生成。更换协作界面不等于更换海螺或配音模型，也不能保证表演自动改善。

当前会话没有海螺视频生成和TTS直连工具。因此本轮已完成素材检查、无字幕参考图与实验包准备；10秒新视频和新音频仍待用户在对应创作页面生成。
