# 通用视频提示词结构与案例复盘

更新：2026-10-20  
目标：复用提示词的组织结构，根据每次剧情重新设计内容、节奏和镜头。

## 使用原则

固定的是需要交代清楚的信息：目标、素材、连续性、逐镜变化、摄影、声音和约束。具体风格、题材、人物、时长、画幅、镜头数量、参考图数量、动作速度、剪辑与运镜全部按本次剧情决定。

真人古装练剑只是[已完成案例](完整提示词-v2.md)，不是后续默认风格。目录名保留用于记录这次实验；本页的方法可以用于其他风格与题材。案例里的 15 秒、六镜、三张参考图、固定机位、无配乐和快速出剑，均不直接套入新任务。

## 统一结构

| 模块 | 要交代的信息 | 按剧情调整的部分 |
| --- | --- | --- |
| 目标与叙事 | 本段发生什么、观众需要看懂什么、情绪怎样变化 | 风格、题材、时长、比例、叙事重点 |
| 素材与参考 | 真实收到的素材、编号、用途、控制范围 | 是否用图、参考数量、首尾帧或其他可用模式 |
| 连续性 | 跨镜需要保持与允许变化的事实 | 人物造型、道具状态、空间、时间与光线 |
| 逐镜内容 | 时间、镜头职责、起始状态、动作或表演、结束状态 | 镜头数量、动作密度、停顿和表演速度 |
| 摄影与剪辑 | 景别、角度、构图、运镜、焦点及镜间衔接 | 全部根据剧情与信息揭示设计 |
| 声音 | 台词、环境声、动作声、配乐与进入退出时间 | 有无对白、音乐、静默及声音视角 |
| 关键约束 | 本片最可能破坏叙事或连续性的问题 | 只选本片相关的限制，不照搬案例负面词 |

这些是写作检查项，不要求每次把每个字段机械塞进生成正文。无关项可省略；有关信息必须明确，避免相互矛盾。

## 先按剧情设计，再填写结构

1. 提炼本段的事件、信息揭示和情绪转折。
2. 为每个镜头确定职责：建立空间、展示动作、捕捉反应、隐藏或揭示信息、完成转场等。
3. 根据职责选择景别、机位、构图、运镜和剪辑，再分配动作与表演时间。
4. 核对参考素材与跨镜状态，确保起点到终点的变化清楚。
5. 适配实际模型的引用方式、时长及镜头语法，输出完整可复制正文。
6. 对照成片复盘；时间段是目标节奏，不保证模型按秒精确执行。

### 运镜如何随剧情变化

以下是选择示例，不是固定搭配：

| 本镜需求 | 可考虑的摄影方式 | 应检查的问题 |
| --- | --- | --- |
| 看清人物与空间关系 | 全景、侧向跟随或有目的的拉远 | 方位、距离和动作路径是否清楚 |
| 强调情绪变化 | 中近景、特写、缓推或固定观察 | 观众能否看到需要的表情变化 |
| 逐步揭示新信息 | 平移、摇镜、拉远或焦点转移 | 信息何时出现，是否提前泄露 |
| 追随行动 | 跟拍、横移、手持或较稳定的追随 | 主体、速度和方向是否仍可辨认 |
| 营造停顿与紧张 | 固定构图、留白、缓慢运动或静默 | 停顿有无叙事作用，是否只是空等 |
| 表达眩晕或失衡 | 有动机的倾斜、旋转或不稳定视角 | 是否符合人物感受且可生成 |

固定机位、硬切、同侧拍摄、末镜露脸都不是通用硬规则。需要越轴、长镜头、背影结尾或慢动作时，应按剧情设计并交代空间与时间变化；不能因为案例曾出现慢动作问题就默认所有视频都要快。

### 动作与节奏怎样写

用可见变化替代抽象形容，例如“收到消息后手指停住，视线从手机移向门口”，而不只写“感到不安”。

动作镜写清接触、受力、方向、先后与落点；表演镜写清视线、表情、呼吸及反应。时长要容纳实际动作和台词，也要容纳有意义的停顿。节奏拖慢时检查准备、动作与停留各占多少，不盲目增加动作。

### 素材与连续性怎样写

每张参考只绑定本次实际需要的职责，如身份、造型、地点、构图或风格；不默认必须有三张，也不把三视图误认作多人。文生视频需在正文写足必要视觉事实，不能无图却只写“保持原样”。

在连续时空中接好上一镜终点与下一镜起点。剧情有换装、换手、时间跳跃或场景切换时，明确交代变化，不把所有事实永远锁死。声音也随剧情设计，不默认无对白或无配乐。

## 通用可填写模板

此处的占位符供编写时填写；交付生成工具的最终正文应完成替换并删除无关项。

```text
【本段目标】
剧情事件：
观众需要获得的信息：
情绪起点→情绪终点：
视觉风格：
目标时长与画幅：
目标模型与生成方式（已知时填写）：

【素材与连续性】
实际参考素材及编号：
每份参考负责控制什么：
跨镜保持项：
本段允许或需要发生的状态变化：

【镜头1｜目标时间：起点—终点】
叙事职责：
起始画面与人物/道具状态：
动作或表演：触发→过程→反应→结束状态
节奏：动作、台词与必要停顿的时间分配
摄影：景别、角度、构图、运镜起止、焦点变化（按需）
声音：对白原文及说话人、环境声、音效、音乐或静默（按需）
结束画面：
与下一镜如何衔接：

【后续镜头】
按剧情所需数量续写上述结构；可以只有一个长镜头。

【全片约束】
必要的连续性与生成边界：
本片特有的风险与限制：
```

## 古装练剑案例复盘（历史证据）

本次案例采用 Seedance 2.0 Fast、15 秒、16:9、三张参考图。创作者对第二版反馈“总体比较满意”。它展示了该结构的一次具体应用，不代表各题材应采用相同摄影或节奏方案。

### 两轮实验的证据

| 项目 | 第一版 | 第二版 |
| --- | --- | --- |
| 创作者反馈 | 动作比较慢，像慢动作 | 总体比较满意 |
| 动作设计 | 握剑、拔剑、斜撩、横扫、收势；准备与展示占时较多 | 增加撤步直刺、上挑斜劈，明确快速出招与立即衔接 |
| 画面抽帧观察 | 存在举剑、转身及持剑停留，结尾脸部构图不理想 | 中段动作变化更多，末段脸部清楚；约 12—15 秒仍偏静 |
| 当前结论 | 用作慢节奏反例 | 作为可继续使用的基准，尚非所有动作逐项通过 |

技术记录：两份上传视频均约 15.072 秒、1280×720、24 fps。复盘按每秒 2 帧抽样查看，时间为近似观察，不能据此确认所有切点、完整剑路或高速动作细节。

第二版实际露脸早于原计划的最后两秒，说明逐秒提示不等于严格时间线执行。两版画面仍可见平台 AI 生成标识；不把“无水印”记为已实现。音频未听检，声音与费用均未验收。视频和参考图未上传本目录。

本次只有两条样片，且第二版同时改变动作数量、节奏、构图等多个变量。不能据此认定某一句提示词单独解决了慢动作，也不推断其他模型同样有效。
