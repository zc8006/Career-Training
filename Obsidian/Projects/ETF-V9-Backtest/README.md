# ETF V8 / V9.1 历史回测

研究用途，不是实盘信号。V9.1目标持有10–30交易日、潜在空间12%–20%、本金上限5000元、计划风险预算300元；没有信号则空仓。

## 本地运行

```bash
python -m pip install -r requirements.txt
python backtest.py
```

输出到 `reports/`：summary.csv、trades.csv、signals.csv、data_status.csv。需要联网下载行情。首次运行或行情源异常时可能失败，**不会生成虚构收益**。

## GitHub Actions

工作流 `.github/workflows/etf-v9-backtest.yml` 在北京时间交易日17:00（UTC 09:00）尝试运行，也支持 Actions -> Run workflow 手动执行。GitHub Actions 的 schedule 可能延迟，且中国节假日不等于工作日；脚本仅按实际日线数据运行。报告作为 workflow artifact 保存30天，不自动提交数据到仓库。

## 交易模型与局限

- 信号仅使用截至当日收盘数据，次日开盘模拟成交；100份整数倍，佣金每边最低5元，滑点0.1%，初始资金5000元。
- V8：连续3日收盘高于MA20，MA20不下降，收盘严格高于前10日最高收盘价。
- V9.1：60日内回撤至少12%，距离60日低点不超过12%，3日不创新低，收盘高于MA10，MA5连续上升，近5日相对沪深300为正；收益空间采用过去60日高点作为可检验的历史阻力代理，至少12%，收益风险比至少2.5。**这些是假设，需回测验证**。
- 首仓上限1500元；结构止损取最近5日低点下方1%，止损距离不超过8%；风险不超过300元。暂不自动加仓，以避免未经验证的组合风险。
- 退出：盘中触及止损则以止损价模拟（跳空低开则按开盘价），盈利10%减仓约1/3；剩余仓位从最高收盘价回撤7%或持仓满30个交易日退出。
- 本版按ETF**逐只独立回测**，不是多ETF共享资金组合回测。单只ETF内资金不超过5000元。V8与V9.1独立比较；尚未覆盖现金分红、停牌、涨跌停无法成交、申赎折溢价、所有交易所规则、数据幸存者偏差；复权行情与可交易价格需要进一步核对。
- 样本外测试、参数敏感性、完整组合回测及真实交易成本校验为下一阶段。不能把历史结果当未来保证。
