# Excel 预览整理版

3 份 .xlsx 共 23 张工作表，按飞书附件预览中的原工作表顺序、名称、行号和列号重建，保留全部已观测行（含空白行）和单元格显示值。

数字、百分比和完整日期保存为对应 Excel 值；百分比和数字保留预览中的显示小数位。类目路径、标识符和 SKU 保留为文本。源预览显示的错误文字会原样保存并列在 xlsx-provenance.json，未新增公式。

第 2 份的使用说明图片以原始图片嵌入，放在原说明文字下方。仅纳入实际保存的附件内图片。

这是从浏览器预览重建的可打开工作簿。原始计算公式、隐藏内容、原始样式、下拉验证、宏及其他未暴露功能没有恢复，核算结果是静态显示值，不会随输入重新计算。请结合原说明使用。
