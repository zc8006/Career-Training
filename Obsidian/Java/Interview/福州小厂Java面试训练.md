## 核心记忆

1. ACID 是原子性、一致性、隔离性、持久性。
2. 持久性是事务提交后结果永久保存，系统重启也不应丢失。
3. `tryLock(2, TimeUnit.SECONDS)` 返回 `true` 后才能执行业务和解锁。
4. `tryLock()` 返回 `false` 时，当前线程没有获得锁，不能调用 `unlock()`。
5. `EXPLAIN` 关注 `type`、`possible_keys`、`key`、`rows`、`Extra`。
6. 线程池处理顺序是核心线程、任务队列、最大线程、拒绝策略。
7. 线程池七个参数包括核心线程数、最大线程数、存活时间、时间单位、任务队列、线程工厂和拒绝策略。
8. Redis 锁提前过期可能导致多个线程同时执行业务。
9. Redis 分布式锁可通过合理过期时间、自动续期和业务幂等降低风险。
10. MyBatis 包含式模糊查询使用 `LIKE CONCAT('%', #{param}, '%')`。
