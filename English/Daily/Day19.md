## Q3 What technologies did you use in this project?

### User Answer

I used the typeScript, Node.js, and Python. I also used the vector search and the embeddings.

### Corrected Version

I used TypeScript, Node.js, and Python.

I also used vector search and embeddings.

### Notes

Do not use "the" before technology names.

Wrong:
- the TypeScript
- the vector search
- the embeddings

Correct:
- TypeScript
- vector search
- embeddings
