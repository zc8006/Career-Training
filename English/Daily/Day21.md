## Project Selection Strategy

When asked:

Tell me about your recent project.

Choose only one project that matches the role.

Examples:
- AI / Agent / GenAI role -> AI RAG demo project
- Java / backend role -> Java or MuleSoft project
- Data Engineer role -> IBM Process Mining / data-related project
- MuleSoft role -> MuleSoft API integration project

Do not explain all projects at once.
