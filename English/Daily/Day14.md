# English Daily - Day14

## Goal

30-minute technical interview training with an AI project focus.

Main rule:
- Use simple English.
- Use short sentences.
- Do not try to explain AI like an expert.
- Explain what the system does, what problem it solves, and how it works.

# Day14 Questions and Answers

## Q1 Tell me about your AI project.

### User Answer

into the REG system, users can upload documents.

### Corrected Version

This was a RAG demo system.

Wrong:
- REG

Correct:
- RAG

## Q4 How does your AI system work?

### User Answer

The biggest challenge was finding the right information.
