# English Wrong Answers

记录不会说、说错、容易卡住的英语句子。

## 记录格式

```text
日期：
场景：
错误表达：
正确表达：
中文意思：
是否已掌握：No / Almost / Yes
```

---

## 示例

### 2026-06-10

场景：介绍技术栈

错误表达：

```text
I use the Java and Spring Boot.
```

正确表达：

```text
I use Java and Spring Boot for development.
```

中文意思：

```text
我使用 Java 和 Spring Boot 进行开发。
```

是否已掌握：Almost

---
