### 本轮纠错记录

1. 原子性不是“同时提交”，而是一个事务中的操作要么全部成功，要么全部回滚。
2. 一致性是事务执行前后数据都符合业务规则和约束，“转账总金额不变”只是一个例子。
3. “不可重复读”是并发读取问题，不是隔离级别；正确级别是“可重复读”。
4. Java 8 种基本数据类型不能遗漏 `boolean`。
5. 线程相关名称应准确写成 `Thread`、`Runnable`、`Callable`、`FutureTask`。
6. 中文面试中使用“输出”“业务处理”“集成测试”，不使用“出力”“结合测试”。

### 本轮 10 句背诵清单

1. 原子性强调事务中的操作不可分割，一致性强调事务前后的数据符合业务规则。
2. MySQL 四种隔离级别是读未提交、读已提交、可重复读、串行化。
3. InnoDB 默认隔离级别是可重复读。
4. Java 8 种基本数据类型是 `byte`、`short`、`int`、`long`、`float`、`double`、`char`、`boolean`。
5. Java 创建线程的常见方式是继承 `Thread`、实现 `Runnable`、使用 `Callable + FutureTask`、使用线程池。
6. 生产项目通常优先使用线程池，以便复用线程、控制线程数量和管理任务。
7. `equals()` 相等的对象，`hashCode()` 必须相同，否则哈希容器可能无法正确去重、查找或更新。
8. Redis 常用于热点缓存、带过期时间的临时数据，以及分布式锁或接口幂等。
9. MuleSoft SOAP 迁移需要保证 WSDL、XML 命名空间和响应结构兼容。
10. 普通去重可使用 `HashSet`，保序去重可使用 `LinkedHashSet` 或有序流的 `distinct()`。
