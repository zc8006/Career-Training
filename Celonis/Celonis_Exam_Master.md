## 重要判断规则

### View 这个词的歧义

```text
Studio / Views / Dashboard 语境：
View = 前端可视化页面或仪表盘。

Build View / OCPM 语境：
View = 数据层的视图逻辑，和 event collection、object-centric model 有关。
```

考试时要根据题干判断语境，不能只看 View 一个词。
