# Celonis - Build Views Notes

## 核心定位

Build Views 主要是 Studio 中的可视化与分析页面。

关键词：

- Studio
- View
- Chart
- Table
- Filter
- Knowledge Model
- PQL Metric
- Process Explorer
- Process Copilot
- AI Annotation

## 重要考点

### Metric PQL

```text
Metric must be wrapped by a standard aggregation function to consolidate values.
```

### Dual axes chart

如果同一张图要同时展示价格和销量这类不同量纲数据，可以使用 dual axes chart。

### Knowledge Model

Knowledge Model 提供可复用的业务指标、维度和语义层内容，View 可以基于 KM 构建图表和分析页面。
