# Japanese Training Master

## 目标

日语训练目标：

- 能进行日本项目面试
- 能说明自己的项目经验
- 能用简单稳定的句型回答技术问题
- 能表达原因、现状、对策
- 能基于仕様書进行技术沟通

## 当前策略

- 不追求复杂表达
- 优先使用固定句型
- 面试中保证清楚、稳定、自然
- 技术问题尽量用“原因 → 现状 → 对策”结构回答

## 自我介绍核心版

```text
周永欣と申します。
システムエンジニアとして、20年以上の経験があります。
これまで、Java、Spring Boot、MuleSoftなどを使って、業務システムの開発を担当してきました。
プログラマーから始まり、SE、サブリーダーとして、設計、開発、テスト、保守を経験しました。
日本向けのプロジェクト経験も長く、仕様書をもとに作業を進めることができます。
今後も、これまでの経験を活かして、安定したシステム開発に貢献したいと考えています。
```

## 技术表达固定句型

### 原因

```text
原因は、既存システムとの連携部分が複雑だったためです。
原因は、仕様の確認が十分ではなかったためです。
```

### 现状

```text
現在、影響範囲を確認しています。
現在、ログを確認しながら原因を調査しています。
```

### 对策

```text
今後、テストケースを追加して、再発防止を行う予定です。
影響を確認しながら、慎重に対応を進めています。
```

## Spring 表达

```text
IoCとDIを使って、オブジェクトをSpringが管理します。
そのため、修正しやすくなります。
部品同士のつながりを弱くすることができます。
```

## 每日训练规则

1. 先复习旧句型
2. 再练新问题
3. 错句必须改成可背版本
4. 面试表达优先简单稳定
5. 复杂技术问题用固定结构回答
