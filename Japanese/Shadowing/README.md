# Shadowing 日本語を話そう！

《Shadowing 日本語を話そう！初～中級編》的跟读练习整理。

## 练习方法

1. 先听完整对话，确认场景和语气。
2. 边听边跟读，尽量不暂停音频。
3. 模仿重音、节奏和语调，不只朗读文字。
4. A、B 角色分别练习，最后脱稿复述。
5. 对说错或不稳定的句子进行记录并反复复习。

## 每日练习建议

- Review：复习上一组 5～10 个对话。
- New：练习新一组 5～10 个对话。
- Strict Mode：逐句纠音，未达到自然、稳定前不跳过。
