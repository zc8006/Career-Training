# Shadowing 自我成长模式

## 目标

- 从“看得懂”提升到“不看文字也能自然说出”。
- 稳定掌握日语的节奏、重音和语调。
- 将教材表达迁移到日常会话与面试回答中。
- 根据错误记录动态复习，掌握后再进入下一组。

## 每日训练流程

每次约30～45分钟。

1. **热身（5分钟）**：复述上次最不稳定的3句话。
2. **复习（10分钟）**：随机抽查上一组5个对话，不看文字回答。
3. **新内容（10～15分钟）**：练习5个新对话，分别扮演A、B。
4. **口语输出（5～10分钟）**：替换人物、地点或时间，生成自己的句子。
5. **严格纠错（5分钟）**：修正发音、助词、时态和语调，错误句进入下次复习。

## 周一至周五节奏

| 星期 | 训练重点 | 完成标准 |
|---|---|---|
| 周一 | 上周弱项复习＋新对话1～5 | 能跟读并理解场景 |
| 周二 | 周一内容抽查＋新对话6～10 | 不看B句也能回答 |
| 周三 | 10个对话混合抽查＋语调强化 | 顺序打乱后仍能回答 |
| 周四 | 角色互换＋替换练习＋自由表达 | 能把句型用于自己的场景 |
| 周五 | 周测＋错句整理＋下周计划 | 正确率达到80%，表达基本流畅 |

## Unit 3 四周安排

| 周次 | 内容 |
|---|---|
| 第1周 | Section 1 |
| 第2周 | Section 2 |
| 第3周 | Section 3 |
| 第4周 | Section 1～3 综合复习与随机对话 |

第4周结束后，优先学习新加入的Section；如果没有新内容，则从错误率最高的对话开始下一轮强化。

## 自动成长规则

- 回答错误或停顿超过3秒：标记为“需复习”。
- 连续两次独立回答正确：标记为“已掌握”。
- 当天正确率低于80%：下一次先复习，不增加难度。
- 当天正确率达到80%：下一次进入新内容，并保留2～3句弱项。
- 周五仍不稳定的句子：自动进入下周一的热身清单。
- 纠错采用 Strict Mode：先指出问题，再给可背版本，重新说正确后才进入下一句。

## 开始口令

```text

Review: 上次弱项
New: 当前进度的5个对话
Mode: Self-Growth + Strict
```

