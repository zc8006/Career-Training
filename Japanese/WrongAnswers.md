# Japanese Wrong Answers

记录日语面试、技术表达、发音、语法上的错题。

## 记录格式

```text
日期：
场景：
错误表达：
正确表达：
中文意思：
是否已掌握：No / Almost / Yes
```

---

## 示例

### Spring / IoC / DI

错误表达：

```text
IoTとAIを使って、オブジェクトを自律が管理します。
```

正确表达：

```text
IoCとDIを使って、オブジェクトをSpringが管理します。
```

中文意思：

```text
使用 IoC 和 DI，由 Spring 来管理对象。
```

是否已掌握：Almost

---

错误表达：

```text
そのため、修正やすくなります。
```

正确表达：

```text
そのため、修正しやすくなります。
```

中文意思：

```text
因此会更容易修改。
```

是否已掌握：Almost
