## 回顾题记录

### 1. 什么是 Stop-The-World（STW）？

用户回答：Full GC 的时候会停止服务。

评分：7/10

纠正：STW 是 JVM 在某些 GC 阶段暂停用户线程，不只是 Full GC 才可能发生；Minor GC 的某些阶段也会有 STW。面试里应说“暂停用户线程”，不要泛化成“停止服务”。

保命句：

> STW 就是 GC 某些阶段暂停用户线程，不只是 Full GC 才会发生。

### 2. 内存泄漏和 OOM 有什么区别？

用户回答：内存泄漏是对象被一直引用不能回收，这种情况很多的话就会发生内存溢出。

评分：9/10

结论：核心正确。

保命句：

> 泄漏是该回收的没回收，溢出是内存真的不够了。

### 3. Java 常见内存泄漏场景有哪些？

用户回答：对象一直被引用，静态的大数据文件。

评分：6/10

纠正：本质是对象无用了但仍被引用；典型场景包括 static List/Map 长期持有对象、缓存无淘汰、监听器未注销、ThreadLocal 在线程池中未 remove。

保命句：

> 内存泄漏本质就是：对象已经不用了，但引用还在，GC 回收不了。

### 4. JVM 常见垃圾回收算法有哪些？

用户回答：复制法、标记清除、标记整理。

评分：9/10

结论：三种基础算法已基本稳定。分代收集应理解为整体策略，而不是与前三者完全同层级的基础算法。

保命句：

> 标记-清除、复制、标记-整理；分代收集是按不同代选择不同回收策略。

### 5. JVM 运行时内存区域主要有哪些？

用户回答：堆、栈、程序计数器、本地方法栈、方法区。

评分：10/10

结论：首次无提示、术语标准地完整输出 5 个区域。

保命句：

> 堆、栈、计数器、本地栈、方法区。

### 6. 年轻代一般分成哪些区域？

用户回答：Minor GC。

评分：2/10

纠正：Minor GC 是回收动作，不是内存区域。年轻代通常是 Eden + S0 + S1。

保命句：

> 年轻代 = Eden + 两个 Survivor。

### 7. Survivor 区主要是干什么的？

用户回答：主要是用来复制对象方便回收。

评分：8/10

纠正：Survivor 主要存放 Minor GC 后仍存活的对象，并配合 S0/S1 的复制过程。

保命句：

> Survivor 放存活对象，S0 / S1 配合复制算法。

### 8. 对象什么时候从年轻代晋升到老年代？

用户回答：多次没有被清除，年龄达标后会晋升；Survivor 不够时也可能提前晋升。

评分：9/10

结论：核心已稳定，只需固定术语“Survivor 区空间不足”。

保命句：

> 对象活得够久就晋升；Survivor 放不下也可能提前晋升。

### 9. GC Roots 常见有哪些？

用户回答：栈 Roots、静态、常量、JNI。

评分：10/10

结论：连续多轮无提示完整输出，进入较稳定阶段。

保命句：

> GC Roots：栈、静态、常量、Native。

### 10. 强、软、弱、虚引用分别有什么特点？

用户回答：强引用通常不会被回收，软引用在空间不足时会被回收，弱引用在 GC 时会被回收，虚引用主要是跟踪回收情况。

评分：10/10

结论：已能完整输出，进入较稳定阶段。

保命句：

> 强不收，软紧张收，弱 GC 收，虚跟踪回收。

## Day60 新题

### 1. 什么是 TLAB？

评分：0/10

核心：TLAB（Thread Local Allocation Buffer）是 Eden 中给每个线程预留的一小块线程私有分配空间，用来减少多线程对象分配时的竞争。TLAB 仍然属于堆，不是栈。

保命句：

> TLAB 是 Eden 里给每个线程准备的一小块私有分配区域，用来减少对象分配时的线程竞争。

### 2. 为什么不能简单理解成 new 出来就直接扔进堆？

评分：0/10

核心：对象通常在堆中，但实际分配时会先看线程自己的 TLAB；TLAB 不够时再走 Eden 其他分配路径，具体还会受对象大小、GC、JVM 参数等影响。

保命句：

> 对象在堆里，但分配时通常先看 TLAB，不能简单理解成直接往堆里塞。

### 3. 什么是逃逸分析？

评分：0/10

核心：JVM/JIT 判断对象是否逃出当前方法或线程，并据此进行优化。

常见优化：标量替换、锁消除等。

保命句：

> 逃逸分析就是看对象有没有跑出当前方法或线程。

### 4. 什么是标量替换？

评分：0/10

核心：如果对象没有逃逸，JIT 可能把对象拆成若干基本变量来使用，减少实际对象分配和 GC 压力。

保命句：

> 标量替换就是把对象拆成基本变量，减少对象创建和 GC 压力。
